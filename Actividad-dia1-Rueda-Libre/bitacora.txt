3. ESTRUCTURA BASE DE index.html
--------------------------------------------------------------
- <!DOCTYPE html>                 -> le indica al navegador que es HTML5.
- <html lang="es">                -> idioma español (accesibilidad y buscadores).
- <meta charset="UTF-8">          -> codificación para tildes y ñ.
- <meta name="viewport" ...>      -> adapta la página al ancho del celular.
- <meta name="description" ...>   -> descripción del negocio para buscadores.
- <title>Rueda Libre | Alquiler de bicicletas en Medellín</title>
- Cuerpo: <h1> con el nombre del negocio, párrafo de bienvenida,
  sección "Nuestros servicios" con <h2> y lista <ul>, y un enlace
  "Reserva por WhatsApp" en el <footer>. Se usaron etiquetas
  semánticas: <header>, <main>, <section>, <footer>.

--------------------------------------------------------------
4. PETICIÓN DEL DOCUMENTO (Live Server + DevTools > Network)
--------------------------------------------------------------
Pasos: clic derecho en index.html > "Open with Live Server",
F12 > pestaña Network > recargar (F5) > clic en la fila "index.html"
> pestaña Headers.

  URL completa : http://127.0.0.1:5500/Actividad-dia1-Rueda-Libre/index.html
  Protocolo    : HTTP (versión HTTP/1.1)
  Host         : 127.0.0.1  (equivale a "localhost", mi propio equipo)
  Puerto       : 5500  (puerto por defecto de Live Server)
  Ruta         : /Actividad-dia1-Rueda-Libre/index.html
  Método       : GET  (el navegador pide/obtiene un recurso)
  Código       : 200 OK  (el servidor encontró y envió la página)

Observación: en la misma pestaña aparece además la petición de
img/logo.svg, porque el navegador pide por separado cada recurso
que el HTML referencia.

--------------------------------------------------------------
5. RUTA QUE NO EXISTE
--------------------------------------------------------------
  URL probada : http://127.0.0.1:5500/Actividad-dia1-Rueda-Libre/promociones.html
  Código      : 404 Not Found
  Significado : el servidor sí está funcionando y recibió la petición,
                pero no existe ningún archivo en esa ruta. Los códigos
                4xx indican un error del lado del cliente (pidió algo
                que no hay); los 5xx serían fallas del servidor.

--------------------------------------------------------------
6. ¿QUÉ PASA CUANDO ALGUIEN ESCRIBE LA DIRECCIÓN DEL SITIO?
   (respuesta para el cliente)
--------------------------------------------------------------
1) El navegador separa la URL: protocolo, dominio, puerto y ruta.
2) Traduce el dominio a una dirección IP (DNS).
3) Se conecta al servidor y envía una petición GET por la ruta.
4) El servidor responde con un código (200, 404...) y el HTML.
5) El navegador lee el HTML, pide las imágenes/CSS/JS que necesita
   y dibuja la página en pantalla.

--------------------------------------------------------------
7. ROLES DE HTML, CSS Y JAVASCRIPT EN RUEDA LIBRE
--------------------------------------------------------------
- HTML (estructura y contenido): define qué hay en la página.
  Ejemplo: el título <h1>Rueda Libre</h1> y la lista <ul> con
  "Alquiler de bicicletas", "Recorridos guiados" y "Taller básico".

- CSS (presentación y diseño): define cómo se ve.
  Ejemplo: colores verdes de la marca, tipografía, y que la lista
  de servicios se muestre como tarjetas en fila en computador y
  en columna en el celular.

- JavaScript (comportamiento e interacción): define qué hace.
  Ejemplo: un formulario de reserva que valide la fecha y arme
  automáticamente el mensaje de WhatsApp con la bicicleta y el
  día elegidos, o un menú desplegable en el celular.
